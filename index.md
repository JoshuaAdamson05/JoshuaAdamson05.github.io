# Projects

## Local Networked Table Football

**Unity | C# | Multiplayer Networking**

A 2D top-down multiplayer football game developed as my Honours project.

The project focused on local network multiplayer and explored different approaches to networking authority and responsiveness.

### What I worked on
- LAN host discovery using UDP broadcasting
- Client-server multiplayer architecture
- Lobby and ready-up systems
- Networked player movement and gameplay
- Experimented with different network authority models to compare responsiveness and consistency
- Performance and network profiling

### Technical areas
`C#` `Unity` `Netcode for GameObjects` `Unity Transport` `Networking`
